# OpenVPN Installer — sosaklingo 2026

A maintained fork of [Nyr/openvpn-install](https://github.com/Nyr/openvpn-install), originally created by Nyr and distributed under the **MIT License**. The **sosaklingo** fork began in 2015 and was modernized in November 2026.

> **Status:** review candidate. Static checks do **not** prove that installation or removal works on every supported Linux distribution. Test on a disposable VM before production.

## Supported environments

Upstream currently targets **Ubuntu 22.04+**, **Debian 11+**, **AlmaLinux / Rocky Linux / CentOS 9+**, and supported Fedora versions. It requires **Bash**, **root** for installation, **systemd**, a working **TUN** device, Internet access and an IPv4 address. Firewall, VPS and network-provider restrictions may require adjustments.

## Safety improvements in this fork

- Based on upstream revision `7ff931a00c37a6806bd1fa8cb61bf3369d963e94` (22 September 2026).
- Easy-RSA **3.2.7** downloaded over HTTPS, then checked against the published **SHA-256** digest before extraction.
- No `--no-check-certificate` and no `comp-lzo`.
- OpenVPN `tls-crypt`, **TLS 1.2 minimum**, and **AES-256-GCM / AES-128-GCM** negotiation.
- No automatic changes to **legacy** installations using `/etc/openvpn/server.conf`.
- `--help`, `--version`, and `--check` (read-only).
- A restrictive `umask` for credentials generated by the installer.
- Automated syntax, smoke and static policy tests.

## Get started

**Download and inspect the script before running anything as root.** For the current maintenance branch:

```bash
curl -fL --proto '=https' --tlsv1.2 \
  -o openvpn-install.sh \
  https://raw.githubusercontent.com/sosaklingo/openvpn-install/modern-2026/openvpn-install.sh
bash -n openvpn-install.sh
bash openvpn-install.sh --help
bash openvpn-install.sh --check
```

Only after reviewing the script, taking backups, and testing on a disposable VM:

```bash
sudo bash ./openvpn-install.sh
```

**Do not use the old 2015 command containing `--no-check-certificate`.** Do not pipe an unaudited network download directly into `bash`.

## Existing servers

Do **not** install this fork over a server that was created by the 2015 script. The legacy installation has different file and service layouts. See [MIGRATION.md](MIGRATION.md). The script refuses to proceed when it detects `/etc/openvpn/server.conf` without the modern server configuration.

## Security and limitations

- No installation or removal has been exercised on a live server in this release.
- Certificate generation still follows the upstream interactive installer. Keep private keys, CA keys, and `.ovpn` client profiles out of GitHub and backups accessible only to administrators.
- The script uses NAT/firewall rules and may interrupt remote access if used incorrectly.
- Avoid changing servers over the VPN connection being modified.
- Modern TLS/cipher selection does not protect a server with unpatched operating system packages.
- Refer to [SECURITY.md](SECURITY.md) for details.
